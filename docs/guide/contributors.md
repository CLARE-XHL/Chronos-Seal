## 如何加入贡献者名单？

只要你通过以下方式之一帮助了 Chronos Seal 项目：

- 提交了有效的 Issue（报告 Bug 或提出改进建议）
- 提交了被合并的 Pull Request
- 在论坛或 Issue 中提供了有价值的技术分析
- 为文档或翻译做出了贡献

请在相关反馈中留下你的 GitHub 用户名或论坛 ID，我会在确认后将你加入贡献者名单。

感谢每一位愿意花时间帮助项目变得更好的人。
