## 网络环境

由于 GitHub 在国内部分地区访问不稳定，建议使用下面的工具优化网络连接。


### 🚀 推荐工具：Watt Toolkit（原 Steam++）

**加速原理**：本地反向代理，仅加速列表中指定的域名，不是全局 VPN。

**它能解决哪些问题**：

- `git clone` 大型仓库时卡住
- GitHub Release 包下载失败或速度极慢
- GitHub Actions 日志加载不出来
- 加载国内访问缓慢的公共 CDN（如 Gravatar 头像）
- 通过 Google 人机验证（reCAPTCHA）
- 浏览 Steam 商店和社区

**下载地址**：[Watt Toolkit 官网](https://steampp.net/)

**开源可信**：Watt Toolkit 是开源项目，源码托管在 [GitHub](https://github.com/BeyondDimension/SteamTools)，采用 GPL-3.0 许可证。如果你对发布的二进制文件不放心，可以自行下载源码编译运行。


### 🔑 证书安装（首次使用）

Watt Toolkit 的加速功能基于本地反向代理，需要系统信任它生成的根证书才能正常工作。部分功能（如加速 GitHub）在不安装证书的情况下可能无法生效。

**首次使用时**：打开 Watt Toolkit，点击左侧菜单的 `系统设置` → `网络加速` 选项卡 → 点击 `安装证书` 按钮即可。

> 如果安装失败，也可以手动安装：进入 Watt Toolkit 安装目录下的 `AppData` 文件夹，找到 `SteamTools.Certificate.pfx` 证书文件，双击 → 选择“本地计算机” → 下一步 → 输入密码（密码在程序的系统设置中有显示） → 选择“将所有证书放入下列存储” → 浏览选择“受信任的根证书颁发机构” → 完成。

**为什么需要这一步**：Watt Toolkit 是开源项目，证书仅用于本地加速，不会外传你的任何数据。如果你对闭源或预编译的二进制文件不放心，可以自行从 GitHub 源码编译运行。

> 注：部分版本在安装后可能会自动弹出证书安装提示，如果没有弹出，按上述步骤手动操作即可。


### ⚠️ 杀毒软件拦截问题

Watt Toolkit 加速部分域名需要修改系统 hosts 文件，这可能会被一些杀毒软件（尤其是 360）拦截或静默阻止。

如果你发现加速后 GitHub 依然无法访问，请检查以下情况：

1. 打开 360 安全卫士或 360 杀毒，查看“已阻止操作”或“拦截记录”
2. 如果看到 Watt Toolkit 或 Steam++ 的操作被阻止，选择“允许”或“信任”
3. 重新启动 Watt Toolkit 的加速服务

其他杀毒软件（腾讯电脑管家、火绒等）也可能存在类似行为，如果遇到加速不生效的情况，可以先暂时退出杀毒软件，确认工具能正常工作后再重新开启（并添加信任列表）。


### 💡 进阶排错：关闭系统 IPv6

如果上述方法都试过了，加速后依然没有效果，可以尝试暂时关闭系统的 IPv6。

**原理**：Watt Toolkit 的加速核心是 DNS 解析和 Hosts 重定向。如果电脑同时开启了 IPv6 且网络环境较差，流量可能会优先走 IPv6 导致加速失效。在系统网络设置里暂时关闭 IPv6，再重新点击加速，通常能解决问题。

> 确认加速成功后，可以重新开启 IPv6，不影响后续使用。


### ⚠️ 重要提醒（请勿滥用）

请务必把它当成**网络优化工具**，不要尝试当 VPN 去访问 Facebook、YouTube 等未列入白名单的网站——它做不到，而且这容易触碰法规红线。

老老实实加速 GitHub 和 Steam 即可。
